# A Deno-style notebook

Written against `deno jupyter`'s APIs (`Deno.jupyter`, `Deno.version`),
and run here on Node through the `cdp-node-deno` kernel's Deno
compatibility shim. The same notebook runs on `cdp-deno`. See
[Notebooks written for Deno](jupyter-api.md#notebooks-written-for-deno).
