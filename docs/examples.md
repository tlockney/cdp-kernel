# Example notebooks

Complete notebooks, shown with the output they produced when they ran.
Each can be downloaded and opened in JupyterLab or VS Code with a
cdp-kernel kernel installed ([Getting started](getting-started.md)).

- [A second notebook](example-second-notebook.md): the step after
  Getting started. Fetches Express's release history from the npm
  registry, reshapes it, draws one Vega-Lite chart and renders a Markdown
  summary, updating one output in place along the way. Runs on `cdp-node`.
- [MoMA's collection](example-moma.md): the Museum of Modern Art's open
  collection data, end to end. Loads the CSV files with Polars, draws charts
  with Observable Plot, renders Markdown reports, and uses a widget and a
  React component. Runs on `cdp-node` or `cdp-deno`.
- [A Deno-style notebook](example-deno-style.md): a notebook written for
  `deno jupyter`, using `Deno.jupyter`, run unchanged on `cdp-deno` and on
  Node with the Deno compatibility shim (`cdp-node-deno`).
- [One package's numbers](example-package-stats.md): a notebook that
  runs as a program. A package name comes in as a parameter
  (`jupyter.params`), and its latest version, release count and
  downloads go out as named results (`jupyter.result`). Runs on
  `cdp-node` under [Ganymede](https://ganymede-server.com/docs/programs),
  or on its own with a default.
- [Comparing packages](example-compare-packages.md): runs the notebook
  above for four packages from another notebook, through Ganymede's
  `jupyter.host()`, then tabulates and charts the results.
- [Tables, SQL and charts](example-data-output.md): `jupyter.table`,
  `jupyter.sql` and `jupyter.chart` on Jupiter's moons and a CSV of
  Seattle weather: tables, DuckDB queries over rows and a file on the
  web, and Vega-Lite and Observable Plot charts drawn as SVG. Runs on
  `cdp-node`.

Ganymede's site also shows two
[agent journals](https://ganymede-server.com/docs/examples#agent-journals):
notebooks Claude Code kept as it worked, run on `cdp-node`, with the
prompts that produced them.

The notebooks are generated by scripts in
[`examples/`](../examples/), which also say how to re-run them.
