# Tables, SQL and charts

`jupyter.table`, `jupyter.sql` and `jupyter.chart` together: Jupiter's
moons as a table, SQL over those rows and over four years of Seattle
weather read from a CSV on the web, and the results drawn with Vega-Lite
and Observable Plot. Every output also carries the text summary an agent
reads. The first run installs DuckDB, Vega, Vega-Lite, linkedom and
Observable Plot from npm. See
[Example notebooks](examples.md) for the others, and
[the `jupyter` namespace](jupyter-api.md#tables) for the calls.
